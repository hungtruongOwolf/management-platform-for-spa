## Lead's reading
1. **Attendance codes and layout.**
   - Drop the P / ĐX / K code badges from the daily book.
   - Each staff member gets their own card (component) instead of rows in one shared table.
   - The four attendance choices are clearly separated: distinct, spaced options, each with its own visual identity (colour/icon), not a run-on segmented strip.
2. **A place to review notes.** Owners and managers need one place to read back every note written in the app later. That covers:
   - visit/session notes;
   - customer profile notes;
   - health notes, for holders of the permission;
   - attendance notes;
   - praise/complaint notes;
   - bonus/penalty reasons;
   - follow-up contact notes;
   - void/correction reasons;
   - end-of-employment reasons, owner only.

   It is searchable and filterable by date range, type, staff and customer, with links back to the source record. Permissions match each note's existing visibility rules.
